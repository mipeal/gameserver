## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the PyO3 module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

## Hand patches (re-apply after regeneration)

- `src/lib.rs` `error()`: a `"struct.error"` arm raising the real Python `struct.error`
  (its type name is `error`); `refresh` regenerates `lib.rs` and drops this arm.
- `rust-anything.json`: `get_flag_regex`, `assert_equals`, `assert_requests_response`,
  `generate_name`, `generate_password`, `generate_random_string`, `generate_dummy_flag`,
  `generate_random_text` moved to `js_only` — they stay Python per ADR-013
  (service-facing / OS-random / take a Python `random.Random`).
- `shadow/gamelib_shadow.py`: `gamelib-sample.py` is skipped (dash in filename, never
  importable) and the `_legacy`/`_call` indexes are remapped accordingly.

## Scope (ADR-013)

Ported: flag encode + regex pattern (`get_flag*`, `get_flag_regex_pattern`), flag-id
generation incl. the usernames wordlist (`generate_flag_id*`, `generate_username`),
validators. The RNG reproduces CPython's `random.Random` bit-for-bit.
